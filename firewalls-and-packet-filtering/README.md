# Firewalls and Packet Filtering
This section contains hands-on labs focused on Linux firewall behavior and packet filtering using iptables. The goal of these labs is to understand how different firewall policy models affect traffic flow, visibility, and system exposure.

The experiments were conducted using multiple Linux virtual machines to simulate real-world firewall and client interactions. Each lab emphasizes verification through positive and negative testing rather than rule creation alone.

## Concepts Demonstrated
- Blacklist vs whitelist firewall policies
- Default ACCEPT vs default DROP behavior
- Stateful packet filtering with conntrack
- Inbound vs outbound traffic control
- TCP behavior under firewall enforcement
- Scanner interpretation of filtered vs rejected traffic

## Lab Organization
Each lab folder includes:
- A concise overview of the objective
- The firewall rules or configurations used
- Screenshots showing verification and rule behavior
- A short analysis of key takeaways

These labs are intended to demonstrate applied network defense reasoning rather than production-ready firewall configurations.
