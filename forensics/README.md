# Forensics
This repository contains hands-on labs and small projects focused on basic digital forensics and post-incident analysis. The work here emphasizes examining artifacts after an event has occurred, identifying suspicious activity, and summarizing findings in a clear and repeatable way.

The goal of these labs is not real-time detection or prevention, but understanding how evidence can be extracted from systems during an investigation.

## Topics Covered
- Authentication and system log analysis
- Identifying failed login patterns
- Basic evidence extraction and reporting
- Post-incident analysis workflows
