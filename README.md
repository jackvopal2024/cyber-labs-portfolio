# Cybersecurity Labs Portfolio

This repository is a curated portfolio of hands-on cybersecurity labs completed as part of upper-level coursework and independent experimentation.

The labs focus on practical network defense concepts, including Linux firewall policy design, packet filtering, stateful inspection, and kernel-level traffic control. Each lab is documented with screenshots, command output, and analysis of observed behavior.

## Topics Covered
- Linux firewalls (iptables)
- Blacklist vs whitelist policy design
- Stateful vs stateless packet filtering
- TCP scanning behavior and RST suppression
- Netfilter kernel modules
- Connection tracking (conntrack)
- Forensic timeline analysis and data exfiltration via USB

## Lab Structure
Each lab folder contains:
- A brief overview of the objective
- The configuration or commands used
- Verification steps and results
- Key takeaways and limitations

This portfolio is intended to demonstrate applied cybersecurity thinking rather than polished production tools.
